# Full-Stack Blog Application with JWT Authentication

A fully responsive MERN stack blog application built as part of the internship milestone. Users can securely register, log in, manage their private dashboard, and perform complete CRUD operations on their blogs with live search and category filters.

## 🚀 Features
- **Secure Authentication:** JWT (JSON Web Tokens) with encrypted password hashing (`bcryptjs`).
- **Full CRUD Functionality:** Create, Read, Update, and Delete personalized blogs.
- **Advanced Filtering:** Live text search filtering alongside categorical sorting.
- **Mobile Responsive UI:** Clean, modern, responsive interface tailored for all screen sizes.
- **Professional Setup:** Documented codebase with complete local architecture.

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, Axios, Modern CSS3
- **Backend:** Node.js, Express.js, JWT, BcryptJS

## 📦 Installation & Local Setup
1. Clone the repository.
2. Navigate to `backend-blog-app` and run `npm install` then `node server.js`.
3. Navigate to `frontend` and run `npm install` then `npm run dev`.
